# 公司新聞脈搏:股價異動快速歸因團隊 (Hermes port)

對 $ARGUMENTS 進行最近新聞偵察與異動歸因。**呢個唔係深度投研,係情報快速響應** — 目標係 10 分鐘內回答:「呢間公司最近發生咗咩?股價異動嘅真因係咩?要不要重審投資論文?」

---

## 適用場景

- 持倉 / 關注股票股價大漲 / 大跌(一般觸發線:單日 ±5%、一周 ±10%)
- 財報後股價異動,想快速搞清市場喺反應咩
- 睇到新聞標題,但唔確定係噪音還是真信號
- **唔適用**:完整投研(用 `/investment-team`)、財報深讀(用 `/earnings-review`)、長期論文跟蹤(用 `/thesis-tracker`)

---

## 執行流程

### 第一步:確認參數與場景

向用戶澄清以下信息(如未喺 $ARGUMENTS 入面提供):

| 參數 | 說明 | 默認 |
|---|---|---|
| **公司名** | 中文 / 英文 / 股票代碼均可 | 必填 |
| **時間窗口** | 偵察新聞嘅回溯日數 | 默認 14 天,財報季可縮到 7 天 |
| **股價異動** | 漲 / 跌幅度 + 時間,如「跌 12% / 3 天」 | 選填,有則用於聚焦歸因 |
| **關注側重** | 公司事件 / 監管 / 行業 / 情緒 | 默認四方平均 |

如果用戶只講咗公司名,先反問:「最近幾多日嘅新聞?有具體嘅股價異動要解釋嗎?」 — **唔好默默假設**。

### 第二步:信息可得性分級

| 等級 | 特徵 | 偵察策略 |
|---|---|---|
| **A 級(信息充裕)** | 大盤股、媒體覆蓋廣、財報季 | 重點係**降噪同歸因** — 信息太多反而難搵真因,每個 agent 要有判斷力,過濾掉「重複轉述」嘅二手新聞 |
| **B 級(信息適中)** | 中小盤、覆蓋一般 | 標準模式,每條關鍵事件附 1-2 個獨立信源 |
| **C 級(信息稀缺)** | 港股小票、新上市、冷門 | 轉入「掃盲模式」 — 可能搵唔到任何能解釋異動嘅新聞,**呢個結論本身就係有價值嘅**(可能是技術性 / 資金面而非基本面) |

將評級告知每個 agent,影響其偵察方式。

### 第三步:啟動 4 個並行偵察 agent(Hermes batch)

> **Hermes 限制**:Batch 最多 3 個。我哋合併「公司事件」+「監管政策」為 1 個 task(都係基本面驅動),「行業對手」獨立,「市場情緒」獨立,合共 3 個 batch task。

| Subagent | 偵察方向 | 維度 |
|---|---|---|
| **agent-events** | 公司事件 + 監管政策 | 基本面 |
| **agent-competitors** | 行業對手 + 替代品威脅 | 行業競爭 |
| **agent-sentiment** | 賣方 + 大 V + 南向資金 + 社交媒體 | 市場情緒 |

每個 subagent 收到自己嘅 goal + context,獨立搜尋新聞,獨立寫一份時間線 + 解讀,返回 summary。

完成後可選擇性 spawn 第 4 個 batch(如果時間窗口 > 14 天或需要更深入監管分析)。

### 第四步:每個 agent 偵察重點

#### agent-events(公司事件 + 監管)

**目標**:搵出呢段時間內呢間公司嘅所有重大事件,並區分:
- 業務事件(併購、新產品、客戶合同、高管變動)
- 財務事件(業績預告、融資、回購、分紅)
- 監管事件(政策變化、執法、訴訟)

```
事件時間線:

2026-07-01 | 騰訊 | 完成對 Stripe 嘅新一輪戰略投資(US$50M)
            | 來源: 公司公告
            | 重要度: 中

2026-06-28 | 騰訊 | 王者榮耀海外版上線新賽季,海外 DAU 突破 5000 萬
            | 來源: 官方 twitter / Sensor Tower
            | 重要度: 中

2026-06-25 | 騰訊 | 監管: 內地直播帶貨新規影響微信小商店
            | 來源: 路透社 / 內地官媒
            | 重要度: 高(直接影響收入)
```

#### agent-competitors(行業對手)

**目標**:同期對手嘅動作,以及替代品威脅。

```
2026-07-02 | 字節 | 抖音電商 GMV 同比 +40%
            | 對騰訊影響: 競爭加劇

2026-06-30 | Meta | Threads 用戶突破 2 億,挑戰 X
            | 對騰訊影響: 國際化競爭,但唔係核心戰場

2026-06-29 | 米哈遊 | 新作《絕區零》海外上線 24 小時內破 1000 萬下載
            | 對騰訊影響: 遊戲收入競爭
```

#### agent-sentiment(市場情緒)

**目標**:從情緒面解讀點解股價異動。

- **賣方研報**:邊幾家大行調整咗評級 / 目標價?
- **大 V 評論**:近期雪球、Twitter、微博嘅關鍵討論
- **南向資金**:過去 14 日係淨買入還是淨賣出?(港股)
- **期權市場**:Put/Call 比有冇急變?(反映對沖需求)
- **融資融券**:餘額變化反映散戶槓桿
- **社交媒體情緒**:自然語言判斷討論嘅 tone

### 第五步:實時跟蹤進度

向用戶實時更新進度(邊啲 agent 已完成、邊啲仍在偵察)。

### 第六步:Team Lead 綜合歸因

> **4 個 agent 嘅結果通常唔會一致**,呢個正係你需要嘅 — 因為股價異動往往係**多因素**。

**歸因優先於羅列** — 唔係列出所有新聞,而係判斷「邊個事件配得上今次股價異動」。

```markdown
## 騰訊股價異動歸因(過去 14 日,跌 10.5%)

### 一句話歸因
呢次 -10.5% 跌幅約 70-80% 由**資金面 + 情緒面**驅動(回購靜默期 + 南向減倉 + 板塊 beta + AI 敘事被奪),20-30% 由**AI 投入翻倍嘅遞延消化**承擔 — **基本面無利空**,賣方維持買入共識,性質上屬於「流動性 + 情緒型回調」,唔係價值事件。

### 異動歸因表
| 候選解釋 | 估算貢獻 | 置信度 |
|---|---|---|
| 回購靜默期消失(結構性,5/13 財報前) | -3% ~ -4% | 高 |
| 南向資金轉向淨賣騰訊 | -2% ~ -3% | 高 |
| AI 敘事被競品奪走(DeepSeek V4 / Qwen3.6 / 月暗 1T) | -1% ~ -2% | 中 |
| 板塊 / 宏觀 beta(油價 + 地緣 + Fed Warsh 鷹派) | -2% ~ -3% | 高 |
| 一季報前避險 | -1% ~ -2% | 中 |
| **基本面惡化** | **0%** | **極高(排除)** |

### 性質判斷:✅ 混合型
70% 資金面 / 情緒面 + 20% AI 長期敘事擔憂 + 10% 一季報前不確定性

### 關鍵反證
- 段永平 4/8 賣騰訊 put(看多)
- 賣方 24 家共識 Strong Buy
- 網易 4/30 逆市漲 2%(排除遊戲行業問題)
- 騰訊跑輸恒科 7 個百分點(恒科月度反而漲 4%)

### 行動建議
- **是否觸發深度研究**:❌ 否(基本面未變)
- **是否需要重審論文**:❌ 否(論文假設全部仍然成立)
- **是否僅觀察**:✅ 是(等待一季報 + 回購恢復)
- **是否調整倉位**:❌ 否(維持)
```

### 第七步:保存報告

寫入 `reports/{公司名}-news-pulse-{YYYYMMDD}.md`。

## 關鍵原則

- **歸因優先於羅列**(唔係所有新聞列一遍)
- **強制性質判斷**(價值事件 / 情緒波動 / 真因不明 / 混合)
- **真因不明都係有用嘅結論**(可能係內幕搶跑)
- **明確行動建議**(係咪觸發深度研究 / 重審論文)
- **唔好 over-react**(短期波動唔等於基本面變)

---

## Token 控制

`/news-pulse` 設計為**快速**(10 分鐘)、**輕量** token 消耗。
- 3 個 batch subagent 並行
- 每個 agent 限時搜尋(< 5 分鐘)
- 唔做深度財報分析(嗰啲用 `/earnings-review`)
