# 巴菲特價值投資買入前 Checklist (Hermes port)

對 $ARGUMENTS 進行買入前 Checklist 篩選。

---

## 執行流程

### 第一步:解析輸入,識別所有待分析公司

**輸入格式**:
- 單公司:`騰訊`
- 多公司對比:`騰訊, 阿里巴巴, 美團, 拼多多`

### 第一步半:AI 研究偏見預警

**信息豐富度評級**:

| 等級 | 特徵 | 應對 |
|---|---|---|
| A 級 | 上市多年、覆蓋廣 | 正常執行 |
| B 級 | 上市 1-3 年、覆蓋有限 | 推算數據標註置信度 |
| C 級 | 冷門 / 新上市 / 新興市場 | 第一性原理模式 |

### 第二步:並行數據收集

> **Hermes adaptation**:用 `delegate_task` 啟動 batch subagent 並行收集數據(每間公司 1 個 subagent,或按 region 拆)。

每個 agent 對其公司提供:
- 業務模式(一句話)
- 5 年收入 / 淨利 / FCF / 毛利率 / ROE
- 市值 + PE / PB / EV/EBITDA
- 股權結構 + 管理層
- 護城河評估(5 類驗證)
- 主要風險

### 第三步:逐公司執行六關 Checklist

```
第一關:能力圈(我能理解嗎?)
    ↓ 通過
第二關:好生意(經濟特徵如何?)
    ↓ 通過
第三關:護城河(競爭優勢深不深?)
    ↓ 通過
第四關:管理層(值得信任嗎?)
    ↓ 通過
第五關:安全邊際(價格便宜嗎?)
    ↓ 通過
第六關:決策紀律(是理性還是 FOMO?)
    ↓ 通過
   ✅ 鏡子測試
```

#### 第一關:能力圈

> **能夠用簡單語言解釋呢間公司做咩嗎?**

- 5 分鐘解釋唔到業務 = 唔入能力圈
- 即使解釋到,**仲要誠實問自己:有冇真正理解商業模式?**

| 公司 | 業務一句話 | 能力圈? |
|---|---|---|
| 騰訊 | 社交 + 遊戲 + 金融 + 雲端 | ✅ 容易理解 |
| 台積電 | 代工最先進晶片 | ✅ 但要明技術路線 |
| 某 biotech | 標靶藥物平台 | ❌ 唔識 |

#### 第二關:好生意

| 維度 | 通過條件 |
|---|---|
| 差異化 | 公司做嘅嘢,其他公司做唔到 / 唔想做的 |
| 定價權 | 過去 5 年提價過幾次? |
| 可持續性 | 5 年後仲會係好生意嗎? |
| 投入產出 | 高資本回報(ROIC > WACC 顯著) |

#### 第三關:護城河(5 類驗證)

| 護城河類型 | 驗證問題 |
|---|---|
| 品牌 / 定價權 | 提價 10% 客戶會走嗎? |
| 轉換成本 | 客戶遷移到對手嘅實際成本? |
| 網絡效應 | 用戶越多,產品越好? |
| 規模效應 | 規模帶來嘅成本優勢有幾大? |
| 技術 / 專利壁壘 | 領先幾年?專利幾時到期? |

#### 第四關:管理層

| 維度 | 驗證問題 |
|---|---|
| 誠信 | 歷史有冇造假 / 內幕交易 / 失信? |
| 能力圈 | 管理層做過咩關鍵決策?成敗? |
| 資本配置 | 過去 5 年併購 / 回購 / 分紅嘅回報? |
| 股東利益 | 持股比例?薪酬結構?減持記錄? |

#### 第五關:安全邊距

| 維度 | 驗證方法 |
|---|---|
| 內在價值估算 | DCF / 三情景估值 |
| 與市價比較 | 當前價 vs 內在價值 |
| 安全邊距 | 至少 20-30% 折讓 |

用 `~/.hermes/scripts/financial/financial_rigor.py three-scenario` 做精確計算。

#### 第六關:決策紀律

> **如果我唔買呢間公司,5 年後會後悔嗎?**

- 如果係,問:點解而家唔買?(通常是因為 FOMO 唔係真嘅)
- 如果唔係,問:點解想買?(通常是因為市場熱)

**鏡子測試**:

> "我以 {價格} 買入 {公司名},因為:
> 1. 呢門生意嘅本質係 {一句話},我理解佢;
> 2. 佢嘅護城河係 {具體},而且喺度變寬;
> 3. 管理層 {具體事蹟},值得信賴;
> 4. 當前價格相當於內在價值嘅 {百分比},有安全邊距;
> 5. 即使我錯咗,下行風險可控,因為 {具體理由}。"

**5 句話講唔完整 = 不買。沒有例外。**

### 第五步:快速否決清單

**8 條紅線 — 一票否決**:

1. 管理層有過誠信污點(造假、欺詐、內幕交易)
2. 業務模式有致命缺陷(持續燒錢、客戶流失)
3. 資產負債表有重大隱藏負債
4. 主要收入來源即將消失(政策風險、技術顛覆)
5. 商譽佔總資產 > 50%(可能隱藏減值風險)
6. 過去 3 年連續虧損且無明確轉盈路徑
7. 股權結構有重大不透明性(VIE、複雜離岸架構)
8. 行業週期高位 + 估值 > 歷史 90 分位

### 第七步:最終結論與寫入文件

**結論分類**:
- ✅ **通過**:六關全過 + 鏡子測試寫得到 5 句話 → 可考慮買入
- ✅ **有條件**:六關大部分過,但有 1-2 個不確定因素 → 需要 `/investment-team` 深度研究
- ❓ **灰色**:五關過 + 1 關失敗 → 持續觀察,等待催化劑
- ❌ **不通過**:觸碰紅線 / 六關失敗 → 永不考慮

寫入 `reports/多公司對比-checklist-{YYYYMMDD}.md`。

## 輸出格式要求

1. 每關獨立標題,清晰結構
2. 多公司時必須出對比表
3. 鏡子測試獨立成段
4. 紅線觸碰明顯標註 ⚠️
5. 結論要明確(通過 / 有條件 / 灰色 / 不通過)

---

## 關鍵原則

- **5 句話講唔完整 = 不買。沒有例外。**(段永平)
- **能力圈 = 知道自己唔識** 比識更重要
- **紅線係一票否決**,唔好「雖然...但...」地妥協
- **鏡子測試**係紀律工具,唔係表演
