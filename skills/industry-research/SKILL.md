# 行業投資研究:產業鏈全景掃描 + 四大師個股分析框架 (Hermes port)

對 $ARGUMENTS 進行行業產業鏈全景研究。

---

## 研究目標

從一個投資主題出發,完成:
1. **投資邏輯鏈構建與驗證**:底層趨勢 → 創造需求 → 受益環節
2. **產業鏈全景圖繪製**:上中下游、卡脖子環節
3. **全球上市公司掃描**:每個環節嘅頭部公司
4. **各環節頭部公司四大師分析**:好生意 / 護城河 / 估值 / 風險
5. **投資組合配置建議**:核心 / 衛星 / 期權 / ETF

---

## 第一步:投資邏輯鏈構建與驗證

### 1.1 畫出邏輯鏈

```
底層趨勢(AI 數據中心電力需求爆發 + 碳中和目標)
   ↓ 導致
穩定清潔基荷電源需求激增
   ↓ 創造
核電重啟 / 新建 / SMR 嘅確定性需求
   ↓ 受益
鈾礦 → 燃料加工 → 設備製造 → 運營商
```

### 1.2 逐環節驗證

對邏輯鏈每個環節問:
- **驅動力真實嗎?** 有無已發生嘅事件支持?
- **時間表合理嗎?** 邊啲環節短期受益,邊啲長期?
- **天花板有幾高?** TAM 估算(用 macrotrends / 行業協會數據)
- **唔確定性喺邊?** 最大風險因素

### 1.3 搵「已發生嘅驗證事件」

| 環節 | 過去 12 個月已發生嘅驗證事件 |
|---|---|
| 鈾礦 | 現貨價 + 30% / Cameco 盈利超預期 |
| 燃料加工 | 西屋 AP1000 新訂單 / Urenco 擴產 |
| 設備製造 | 中國一重訂單 + 40% |
| 運營商 | 核電重啟政策(中國 2024 國務院批 5 個新反應堆) |

**冇驗證事件嘅環節 = 純敘事,降低權重。**

## 第二步:產業鏈全景圖繪製

### 2.1 繪製產業鏈結構

**模板**(以核電為例):

| 環節 | 全球代表公司 | 中國代表 | 進入壁壘 | 利潤率 | 景氣度 |
|---|---|---|---|---|---|
| 上游:鈾礦 | Cameco, Kazatomprom | 中核鈾業 | 高(資源稀缺) | 高(40%+) | 上升 |
| 中游:燃料加工 | Westinghouse, Urenco | 中核建 | 極高(技術 + 牌照) | 中(15-20%) | 上升 |
| 中游:設備製造 | 中國一重, 上海電氣, Doosan | 中國一重 / 電氣 | 高(技術認證) | 中(10-15%) | 上升 |
| 下游:運營 | EDF, Exelon, 中國廣核 | 中核 / 廣核 | 極高(牌照) | 中(15%) | 上升 |
| 新興:SMR | NuScale, Nano Nuclear | 中核 / 國電投 | 高 | n/a | 早期 |

### 2.2 識別每個環節嘅「生意特徵」

| 環節 | 生意類型 | 定價權 | 週期性 | 護城河 |
|---|---|---|---|---|
| 鈾礦 | 資源型 | 高(壟斷資源) | 強 | 資源儲量 |
| 燃料加工 | 服務型 | 中(長期合約) | 中 | 技術 + 牌照 |
| 設備製造 | 訂單型 | 中 | 中 | 客戶認證 |
| 運營商 | 牌照型 | 高(政府定價) | 弱 | 牌照壟斷 |

### 2.3 標記「卡脖子環節」

| 卡脖子類型 | 環節 | 中國處境 |
|---|---|---|
| 資源 | 鈾礦(對外依存 70%+) | 戰略缺口 |
| 技術 | SMR 第四代反應堆 | 研發中 |
| 設備 | 大型鍛件 | 部分突破 |

## AI 研究偏見自覺:行業研究嘅特殊陷阱

| 陷阱 | 描述 | 應對 |
|---|---|---|
| **敘事偏差** | 容易寫成「行業前景一片光明」 | 列反方觀點、邊啲環節唔受益 |
| **龍頭偏好** | 默認龍頭係最佳選擇 | 對標「第二梯隊」嘅機會 |
| **英文偏好** | 默認美股龍頭比 A 股好 | 對標同類中國公司嘅估值差異 |
| **故事偏好** | 容易寫「下一個 X 公司」 | 量化估值,避免故事化 |
| **上市偏好** | 忽略一級市場核心玩家 | 強制列「未來 IPO 候選」 |

## 第三步:全球上市公司掃描

> **Hermes adaptation**:用 `delegate_task` 啟動 batch subagent 並行掃描唔同 region(美股 / 港股 / A 股 / 歐日),避免單個 subagent 燒太多 token。

| Subagent | 範圍 |
|---|---|
| **agent-region-1** | 美股 + 加拿大 + 澳洲 |
| **agent-region-2** | 港股 + A 股 |
| **agent-region-3** | 歐洲 + 日本 + 其他 |

每個 agent 對應 region 嘅每個環節列出**市值前 5 + 高增長前 5**公司,並提供:
- 公司名 + ticker
- 市值 + 主要業務
- 簡單估值指標(PE / PB / EV/EBITDA)
- 在該環節嘅市場份額

### 輸出格式

```markdown
## 環節:鈾礦
| 公司 | Ticker | 市值 | 市佔 | PE | PB | 評分 |
|---|---|---|---|---|---|---|
| Cameco | CCJ | $25B | 15% | 35 | 2.8 | ★★★★★ |
| Kazatomprom | KAP.L | $10B | 12% | 18 | 1.5 | ★★★★ |
| ...
```

## 第四步:各環節頭部公司四大師分析

對每個環節揀 1-2 個**最具代表性**嘅公司做深度四大師分析(用 `/investment-team` skill):

```
生意質量(段永平):好生意 / 壟斷資源?
護城河(巴菲特):寬護城河 5 類驗證
行業競爭(芒格):波特五力 + 進入者威脅
風險與文明趨勢(李錄):10 年確定性 + 替代品風險
```

## 第五步:投資組合配置建議

```
| 層級 | 倉位 | 標的 | 環節 | 核心邏輯 | 風險 |
|---|---|---|---|---|---|
| 核心 | 50% | 中國廣核 / Cameco | 運營 + 鈾礦 | 確定性最高 | 政策 / 估值 |
| 衛星 | 30% | 中國一重 / 東方電氣 | 設備 | 國產替代 | 訂單波動 |
| 期權 | 15% | NuScale / Nano Nuclear | SMR | 高彈性 | 技術 / 商業化 |
| ETF | 替代 | URA / URNM | 全鏈 | 懶人方案 | 行業 beta |
```

**核心 / 衛星 / 期權嘅邏輯**:
- **核心倉**:確定性最高,大跌敢加倉
- **衛星倉**:中等彈性,博取超額收益
- **期權倉**:高風險高彈性,小倉位博 10 倍
- **ETF**:無時間研究個股嘅替代

## Token 控制

行業研究範圍廣(可能 30-50 間公司),token 消耗高。
- 用 `delegate_task` 拆 region 並行,避免單 agent 燒 token
- 唔好為咗「全面」而分析全部公司,揀代表性即可
- 對有興趣嘅 3-5 間公司先用 `/investment-team` 做深度
