# 財報精讀團隊:四大師並行解讀 + 公眾號發布 (Hermes port)

對 $ARGUMENTS 進行團隊化財報精讀分析。四大師並行解讀財報,編輯潤色成文,讀者評審把關質量,最終產出可直接發布嘅公眾號文章。

**支持輸入格式**:`公司名 季度`,例如:`騰訊 2025Q4`、`PDD 2025年報`、`美團 最新`

---

## 設計理念

一份好嘅財報分析要解決兩個問題:
1. **自己睇得明未來** — 需要四個唔同視角嘅深度研究
2. **讀者睇得明價值** — 需要編輯潤色同讀者視角嘅質量把關

本 skill 嘅流程分三階段:
- **階段一 · 研究**:四大師並行精讀財報(段永平睇生意本質、巴菲特審財務質量、芒格讀競爭變化、李錄獵風險信號)
- **階段二 · 合成**:Team Lead 綜合四個視角,產出研究報告初稿
- **階段三 · 發布**:編輯 Agent 改寫為公眾號文章 + 讀者評審 Agent 提出修改意見 → Team Lead 定稿

---

## 階段一:四大師並行研究

### 第一步:獲取一手資料

> **Hermes adaptation**:用 `delegate_task` 啟動 batch subagent 並行獲取材料。

| 資料類型 | 獲取來源 | 優先級 |
|---|---|---|
| 財報原文 | 公司 IR 頁面、SEC EDGAR(美股)、港交所披露易(港股)、巨潮資訊網(A 股) | 最高 |
| 業績電話會紀要 | Seeking Alpha、公司 IR 頁面、雪球 | 最高 |
| 管理層致股東信 | 年報中提取 | 高(僅年報時) |
| 上一期財報 / 電話會 | 同上 | 高(用於承諾追蹤) |

**資料可得性評級**:

| 等級 | 特徵 | 影響 |
|---|---|---|
| **A 級** | 獲取到完整原文 | 正常執行全部步驟 |
| **B 級** | 僅獲取到部分原文或第三方匯總 | 標註「非原始來源」,降低附注分析權重 |
| **C 級** | 僅有新聞報道同數據網站摘要 | 聚焦核心數據變化,跳過附注挖掘,標註「一手資料不足」 |

將資料可得性評級告知每個 agent,影響其分析深度。

### 第二步:展示團隊框架

| 階段 | 角色 | 大師 / 定位 | 核心任務 |
|---|---|---|---|
| 研究 | **Team Lead**(你自己) | 總協調 | 統籌、合成、定稿 |
| 研究 | 生意本質解讀者 | 段永平 | 呢門生意變好咗還是變差咗? |
| 研究 | 財務質量審計師 | 巴菲特 | 賺嘅係真錢還是假錢? |
| 研究 | 競爭變化解讀者 | 芒格 | 競爭格局喺點變? |
| 研究 | 風險信號獵手 | 李錄 | 管理層喺隱瞞咩? |
| 發布 | 編輯 | 公眾號寫作 | 將研究報告改寫成好文章 |
| 發布 | 讀者評審 | 普通投資者 | 讀者睇得明嗎?有收穫嗎? |

### 第三步:啟動 3 個並行研究 subagent(Hermes batch 限制)

> **Hermes 限制**:Batch 最多 3 個。我哋合併「段永平 + 巴菲特」為 1 個 task(都係看生意本質同財務質量,核心),「芒格 + 李錄」為第 2 個 task(都係看外部環境)。第 3 個 batch 用嚟啟動「編輯 + 讀者評審」嘅初步 mockup。

| Subagent | 任務 |
|---|---|
| **agent-research-1** | 生意本質(段永平)+ 財務質量(巴菲特) |
| **agent-research-2** | 競爭變化(芒格)+ 風險信號(李錄) |
| **agent-research-3** | 一手資料獲取 + 預備編輯潤色 |

完成後,team-lead 自己綜合 4 個視角,再 spawn「編輯」同「讀者評審」sequential agents。

---

#### Agent 1:生意本質解讀(段永平視角)

**核心問題:呢份財報反映嘅生意本質,變好咗還是變差咗?**

> 段永平:「投資就係買一門生意。睇財報唔係睇數字,係睇呢門生意有冇變。」

分析內容:
1. **收入結構拆解與解讀**:分業務 / 分地區收入,邊啲喺加速、邊啲喺減速;唔只係列數字 — 每個業務板塊反映咗咩商業邏輯;收入增長嚟自「量」還是「價」?邊種更健康?
2. **用戶 / 客戶價值變化**:DAU / MAU / 付費用戶等運營指標變化;用戶時長、ARPU、留存率等質量指標;平台 / 產品對用戶嘅價值喺增強還是減弱?
3. **護城河檢測**:毛利率變化反映定價權是否穩固;研發投入 vs 收入比嘅變化方向;核心運營指標嘅同業對比

#### Agent 2:財務質量審計(巴菲特視角)

**核心問題:賺嘅係真錢還是假錢?**

> 巴菲特:「盈利嘅質量取決於現金流嘅支持。」

分析內容:
1. **現金流質量**:經營活動現金流 / 淨利潤比(> 1 為健康);自由現金流 margin 同環比 / 同比變化;CapEx 嘅合理性質(維護性 vs 增長性)
2. **利潤可持續性**:Non-GAAP vs GAAP 嘅差異(SBC、併購攤銷等);一次性損益佔比;折舊政策嘅激進 / 保守程度
3. **資產負債表健康度**:淨現金 vs 總負債;應收賬款 / 收入比(> 20% 警示);存貨週轉天數變化
4. **資本回報**:ROE / ROA / ROIC 趨勢;股東權益回報嘅穩定性
5. **盈利質量陷阱**:管理層有無 switch 過會計準則?有冇提前確認收入嘅跡象?

#### Agent 3:競爭變化解讀(芒格視角)

**核心問題:競爭格局喺點變?**

分析內容:
1. **市佔率變化**:分業務 / 分地區市佔率嘅增減;邊啲業務被新進入者蠶食?
2. **同業對比**:核心指標 vs 主要競爭對手(增長、毛利率、FCF margin 等);差異嘅原因係自身變化定係對手變化?
3. **新進入者威脅**:有冇新進入者喺蠶食市佔?管理層點應對?

#### Agent 4:風險信號獵手(李錄視角)

**核心問題:管理層喺隱瞞咩?**

分析內容:
1. **風險章節增刪**:對比上一份報告,風險章節有冇新加入嘅風險?有冇刪走舊風險?
2. **管理層避談**:電話會入面有冇問題被刻意迴避?邊啲指標俾唔到具體數字?
3. **指引可信度**:管理層嘅指引 vs 實際結果(過往 3-4 季嘅達成率)
4. **非常規信號**:SBC 大幅變化?商譽減值?新會計政策?

### 第四步:3 個 subagent 完成後,Team Lead 綜合

讀取 3 份 subagent report,綜合產出**研究報告初稿**:

```
一、核心數據速覽
二、四大師視角綜合
   - 生意本質(段永平)
   - 財務質量(巴菲特)
   - 競爭變化(芒格)
   - 風險信號(李錄)
三、財務數據交叉驗證結果
   - 用 financial_rigor 工具驗證
四、結論:呢份財報講咗咩故事?
   - 一句話總結
   - 投資論點嘅支持 / 反對
```

---

## 階段二:合成(Team Lead)

Team Lead 綜合 3 份 subagent report,**唔係簡單拼接**:
- 識別 4 個視角之間嘅**張力**(段永平話生意變好,芒格話競爭加劇 → 點平衡?)
- 提出自己嘅 trade-off 判斷
- 標註「研究置信度」vs「投資確定性」嘅區別

---

## 階段三:發布(編輯 + 讀者評審)

### 第五步:編輯 Agent(sequential spawn)

**任務**:將 Team Lead 嘅研究報告改寫成公眾號文章。

**編輯原則**:
- 前 18-20 字必須能獨立企住(手機預覽)
- 段落短,有 sub-header
- 善用 markdown 表格同列表
- 避免「顯然 / 必然 / 一定」等絕對化用詞
- 加入 1-2 個段永平 / 巴菲特金句(唔堆砌)
- 文末「不構成投資建議」

### 第六步:讀者評審 Agent(sequential spawn)

**任務**:扮普通投資者讀者,通讀全文,提出:
1. 邊度睇唔明?(技術術語 / 邏輯跳躍)
2. 邊度悶?(可以刪走嘅段落)
3. 邊度少咗?(應該深入但無深入嘅部分)
4. 整體 1-10 分,值唔值得讀?

### 第七步:Team Lead 定稿

整合編輯反饋 + 讀者評審 → 最終版本。

### 第八步:保存

寫入 `reports/{公司名}-earnings-team-{YYYYQ_N}.md`,例如 `reports/騰訊-earnings-team-2025Q4.md`。

## Token 控制

呢個 skill **極燒 token** — 3 個研究 subagent + 編輯 + 讀者評審 + Team Lead 綜合,可能 6-8 個 LLM call 嘅 token 量。

**強烈建議**:
- 只對**重要持倉嘅關鍵季度**(年報、轉折點)先用本 skill
- 一般季報用 `/earnings-review`(單 agent)
- 快速歸因用 `/news-pulse`
- 出發布級別內容時先考慮本 skill
