# 供應鏈瓶頸獵手:AI 驅動嘅全球產業鏈瓶頸套利 (Hermes port)

對 $ARGUMENTS 進行供應鏈瓶頸掃描。

---

## 核心理念

與其搵「邊隻股票會升」,不如搵**「邊個環節有物理產能 / 牌照 / 資源 / 技術壁壘,導致供應追唔上需求」**。呢啲瓶頸帶嚟嘅係**定價權 + 高利潤率 + 多年保護**,唔係短期炒作。

---

## 第一步:超級趨勢確認

### 1.1 趨勢篩選標準

| 標準 | 說明 |
|---|---|
| **持續時間 > 10 年** | 短週期炒作唔算超級趨勢 |
| **全球性 / 非地區性** | 只影響一個國家嘅唔算 |
| **實體經濟支撐** | 唔係純敘事,有實質 capex / 政策 / 消費支撐 |
| **可量化 TAM** | 用 macrotrends / IEA / 行業協會數據 |
| **已開始而非將開始** | 避免預測過早 |

### 1.2 當前跟蹤嘅超級趨勢清單

| 趨勢 | 持續期 | 預期 TAM | 主要受惠地 |
|---|---|---|---|
| AI 算力 | 2023-2035 | $5T+ | 美 / 台 / 韓 |
| AI 基建電力 | 2024-2040 | $2T+ | 美 / 中 |
| 電動車 + 電池 | 2020-2040 | $10T+ | 中 / 歐 / 美 |
| 核電重啟 | 2024-2050 | $1.5T+ | 中 / 法 / 美 / 韓 |
| 機器人 + 自動化 | 2025-2050 | $3T+ | 日 / 德 / 中 |
| 太空經濟 | 2025-2050 | $1T+ | 美 |
| 生物製藥(ADC / GLP-1) | 2023-2040 | $1T+ | 美 / 歐 |
| 稀土 + 關鍵礦產 | 2024-2050 | $500B+ | 中 / 美 / 澳 |

### 1.3 趨勢驗證輸出

對每個超級趨勢提供:
- **核心驅動力**(政策 / 技術 / 人口結構)
- **過去 24 個月已發生嘅驗證事件**
- **capex 數據**(全球 / 按地區)
- **預期未來 3-5 年增量**

## 第二步:供應鏈物理拆解

### 2.1 分層拆解框架

按價值鏈**由上游到下游**逐環節拆解:

```
[趨勢:AI 算力]
  ↑ 拉動
[需求:AI 訓練 / 推理算力爆發]
  ↑ 推動
[瓶頸 1:先進製程晶片(7nm 以下)]
  ↑ 供給
[瓶頸 2:HBM 高頻寬記憶體]
  ↑ 供給
[瓶頸 3:CoWoS 先進封裝]
  ↑ 供給
[瓶頸 4:數據中心電力]
  ↑ 拉動
[瓶頸 5:變壓器 + 配電設備]
```

### 2.2 以 AI 基礎設施為例嘅拆解模板

| 環節 | 全球龍頭 | 進入壁壘 | 當前供需 | 預期未來 3 年 |
|---|---|---|---|---|
| 先進製程晶圓 | TSMC / Samsung | 極高 | 緊張 | 持續緊張(2nm 排隊到 2027) |
| HBM 記憶體 | SK Hynix / Samsung / Micron | 高 | 極緊張 | 持續 |
| CoWoS 封裝 | TSMC | 極高 | 緊張 | 持續(TSMC 產能擴張 50%) |
| 數據中心電力 | 公用事業 | 中(牌照) | 緊張(AI 用電 4 倍) | 持續 |
| 變壓器 + 配電 | Eaton / 特變電工 | 中 | 緊張(交期 2 年) | 持續 |
| 散熱(液冷) | Vertiv / 中國廠商 | 中 | 緊張 | 持續 |
| UPS 應急電源 | Vertiv / Schneider | 中 | 中 | 緊張 |

### 2.3 其他趨勢嘅拆解

對其他超級趨勢,按同樣框架:
- **核電**:鈾礦 / 燃料加工 / 設備 / 運營 / SMR
- **電動車**:鋰 / 鈷 / 鎳 / 電池正負極 / 隔膜 / 電機 / 整車
- **稀土**:勘探 / 開採 / 冶煉 / 加工 / 應用(磁鐵 / 催化劑)
- **機器人**:減速器 / 伺服電機 / 控制器 / 感測器 / AI 模型 / 整機

## 第三步:瓶頸識別 — 搵「咽喉」

### 3.1 瓶頸判定 6 條標準

| # | 標準 | 驗證方法 |
|---|---|---|
| 1 | **物理產能受限** | 排隊 / 交期延長(>12 個月) |
| 2 | **牌照 / 監管壟斷** | 牌照數有限(全球 < 10 個) |
| 3 | **資源稀缺** | 全球儲量集中(< 3 個國家佔 70%+) |
| 4 | **技術壁壘** | 進入需多年研發 + 客戶認證 |
| 5 | **資本密集** | 單項目 capex > $5B |
| 6 | **客戶黏性** | 一旦切入很難被取代(設計鎖定) |

**符合 ≥ 3 條 = 真正瓶頸**(S/A 級)
**符合 2 條 = 候選瓶頸**(B 級,值得持續追蹤)
**符合 ≤ 1 條 = 假瓶頸**(可能被新進入者打破)

### 3.2 瓶頸地圖輸出

```markdown
## {超級趨勢} 瓶頸地圖

### S 級瓶頸(極高確定性,必投)
| 環節 | 6 條標準 | 代表公司 |
|---|---|---|
| 先進製程晶圓 | 1, 4, 5, 6 | TSMC |
| HBM | 1, 4, 5 | SK Hynix |
| 鈾礦 | 2, 3, 4 | Cameco |

### A 級瓶頸(高確定性,重點關注)
| CoWoS 封裝 | 1, 4, 5 | TSMC |
| 變壓器 | 5 | Eaton / 特變電工 |
| 稀土加工 | 2, 4 | 中國廠商 |

### B 級瓶頸(候選,持續追蹤)
| 數據中心 | 5 | 公用事業 |
| SMR | 4, 5 | NuScale |

### C 級 / 假瓶頸(短期供需失衡,容易被打破)
| NAND Flash | 1 | 暫時緊張,但 Samsung / Micron 隨時可擴產 |
```

## 第四步:公司篩選 — 從瓶頸到標的

> **Hermes adaptation**:用 `delegate_task` 啟動 3 個 batch subagent(美股 / 港 A 股 / 歐日韓),對每個 S 級 / A 級瓶頸列出全球上市公司 + 估值。

### 4.1 對每個 S 級和 A 級瓶頸,搵出所有相關上市公司

**輸出格式**:

```markdown
### 瓶頸:CoWoS 先進封裝

#### 全球龍頭
| 公司 | Ticker | 市值 | 市佔 | PE | 評分 |
|---|---|---|---|---|---|
| TSMC | TSM | $800B | 92% | 22 | ★★★★★ |

#### 潛在挑戰者(可能打破壟斷)
| Samsung | 005930.KS | $400B | 8% | 15 | ★★★ |
```

### 4.2 對每間公司跑 `/quality-screen` 7 條去劣指標

剔除 ROE / FCF / 負債率唔過嘅公司。

### 4.3 對通過嘅公司做四大師快速分析

- **段永平**:呢個瓶頸係咪真正嘅護城河?(10 年後仲喺唔喺度?)
- **巴菲特**:估值有冇安全邊際?(PE / PB / FCF Yield)
- **芒格**:有無可能被新技術打破?(CoWoS → 玻璃基板 / 3D 封裝?)
- **李錄**:呢個環節喺文明趨勢入面扮演咩角色?

## 第五步:推薦組合

按**確定性 + 進攻性**分層:

| 層級 | 倉位 | 標的特徵 |
|---|---|---|
| **核心** | 50% | S 級瓶頸龍頭,高確定性 |
| **衛星** | 30% | A 級瓶頸龍頭 + 挑戰者 |
| **期權** | 15% | B 級瓶頸潛在突破者 |
| **ETF** | 替代 | 全鏈覆蓋(SOXX / LIT / URA) |

## 第六步:瓶頸解除時間表

每個瓶頸提供:
- **當前供需缺口**(量化)
- **產能擴張計劃**(公司 capex 指引)
- **預期解除時間**(短期 < 1 年 / 中期 1-3 年 / 長期 > 3 年)

**短中期難以解除 = 多年保護 = 真正投資價值**

## 第七步:輸出報告

寫入 `reports/{趨勢}-bottleneck-{YYYYMMDD}.md`,例如 `reports/AI-bottleneck-20260704.md`。

---

## Token 控制

`bottleneck-hunter` 涉及多個超級趨勢 × 多個環節 × 多間公司,token 消耗極高。建議:
- 每次只處理 1 個超級趨勢
- 用 `delegate_task` 拆 region batch 處理
- 瓶頸判定用 framework 自動套用,唔需要 LLM 重複推理

## 報告實戰範例

`/bottleneck-hunter AI 基建電力` 已於 2026-07-02 完成,識別 S 級瓶頸 3 個 + A 級 4 個 + B 級 5 個。完整報告見 `reports/AI基建電力-bottleneck-20260702.md`。

**核心發現**:變壓器 + 配電設備係最被低估嘅瓶頸(Eaton / 特變電工) — 因為 AI 數據中心電力需求 4 倍增長,但大型變壓器交期已延長到 2 年。
