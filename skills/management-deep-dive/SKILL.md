# 管理層縱深研究:買股票就係買人 (Hermes port)

對 $ARGUMENTS 進行管理層深度研究。

**支持輸入格式**:`公司名` 或 `人名 公司名`,例如:`美團`、`王興 美團`、`黃仁勳 英偉達`

> 「買股票就係買人。搵到你信任嘅人,然後長期持有。」 — 段永平
>
> 「評估管理層,要望佢哋喺冇人睇嘅時候做咩。」 — 巴菲特

---

## 設計理念

大多數投資分析對管理層嘅評估停留喺表面:履歷、持股比例、薪酬。但巴菲特花大量時間**同管理層食飯傾偈**,李錄講**佢投資嘅本質係投人**,段永平話**買股票就係買人**。

本 skill 係 `/investment-research` 第五步管理層評估嘅**深化版**。當標準投資研究中管理層評分唔確定(★★★ 或以下)、或管理層係核心投資邏輯時,使用本 skill 做縱深研究。

AI 無法同管理層食飯,但可以通過公開信息做到:
- **追蹤管理層嘅話與做係咪一致**(承諾 vs 兌現)
- **分析每一筆重大資本配置決策嘅回報**
- **從困難時期嘅決策中推斷品格**
- **通過員工 / 商家 / 客戶嘅反饋側面驗證**

## 執行流程

### 第一步:識別關鍵管理層並啟動並行數據收集

用 `web_search` 確認以下關鍵人物:

| 角色 | 姓名 | 任期 | 背景 | 持股 / 期權 |
|---|---|---|---|---|
| CEO / 董事長 | | | | |
| CFO | | | | |
| 創辦人(如唔在位) | | | | |
| 實際控制人(如不同於 CEO) | | | | |
| 其他關鍵高管 | | | | |

**注意**:區分「邊個喺做決策」和「邊個嘅名喺頭銜上」。有啲公司創辦人雖然卸任但仍係靈魂人物(如黃崢之於拼多多)。

確認關鍵人物後,用 `delegate_task` 啟動多個 background subagent **並行**收集以下數據:

> **Hermes 限制**:Batch mode 最多 3 個 task。我哋合併「發言記錄」+「資本配置」為 1 個 task,「治理」+「側面驗證」分開,合共 3 個 batch tasks。

| Subagent | 任務 |
|---|---|
| **agent-1** | CEO 公開發言 + 資本配置決策記錄(合併) |
| **agent-2** | 治理結構 + 薪酬合理性 |
| **agent-3** | 員工 / 客戶 / 行業口碑側面驗證 |

每個 subagent 收到自己嘅 goal + context,獨立搜尋+獨立寫 markdown report,返回 summary。

### 第二步:CEO 能力圈評估

#### 2.1 戰略眼光

搜 CEO 過去 5 年嘅公開發言(股東信、電話會、採訪、社交媒體),提取佢對以下問題嘅判斷:

| 時間 | CEO 嘅判斷 / 預測 | 實際結果 | 準確度 |
|---|---|---|---|
| | 「我哋認為 X 市場會...」 | X 市場實際... | ✅ / ❌ |
| | 「未來 3 年我哋嘅重點係...」 | 實際執行... | ✅ / ❌ |

**關鍵問題**:
- CEO 有冇做過超前於市場嘅正確判斷?
- CEO 有冇喺大家都睇好嘅時候保持冷靜?
- CEO 對行業趨勢嘅理解係跟隨市場仲係獨立思考?

#### 2.2 執行能力

| 維度 | 評估 | 證據 |
|---|---|---|
| 戰略到落地 | 講咗嘅事做到咗嗎? | |
| 組織能力 | 能不能吸引同留住人才? | |
| 危機處理 | 遇到困難時點應對? | |
| 迭代速度 | 犯錯後糾正嘅速度快嗎? | |

### 第三步:誠信度評估(最重要)

**巴菲特**:「我哋搵三種品質:正直、智慧同精力。如果冇第一種,後兩種會害死你。」

#### 3.1 承諾 vs 兌現追蹤

從過去 3 年嘅財報電話會、股東信、公開採訪中,提取管理層做過嘅**具體承諾**:

| # | 時間 | 承諾內容 | 承諾場合 | 兌現情況 | 評價 |
|---|---|---|---|---|---|
| 1 | | 「我哋將喺 2025 年實現 X 業務盈利」 | 2024 年報電話會 | | ✅ / ⚠️ / ❌ |
| 2 | | 「我哋計劃回購 $X 億」 | 2024 股東信 | | ✅ / ⚠️ / ❌ |

**兌現率統計**:

| 承諾兌現率 | 評價 |
|---|---|
| > 80% | 優秀 — 講到做到 |
| 60-80% | 合格 — 大方向啱但執行有偏差 |
| 40-60% | 令人擔憂 — 承諾過多交付不足 |
| < 40% | 嚴重問題 — 唔可信賴 |

#### 3.2 困難時期嘅表現

搜公司歷史上遭遇嘅重大危機 / 困難(股價暴跌、業績 miss、監管衝擊、競爭加劇),分析管理層嘅應對:

| 危機事件 | 時間 | 管理層反應 | 事後回睇嘅評價 |
|---|---|---|---|

**關注**:
- 係主動溝通仲係躲避?
- 係歸因內部仲係甩鍋外部?
- 係趁機做困難但正確嘅事,仲係選擇短期討好市場?

#### 3.3 對利益相關方嘅態度

| 利益相關方 | 管理層態度 | 證據 | 評價 |
|---|---|---|---|
| 股東 | 尊重 / 忽視 / 利用 | | |
| 員工 | 善待 / 壓榨 / 漠視 | | |
| 客戶 / 用戶 | 以客戶為中心 / 短期榨取 | | |
| 商家 / 供應商 | 公平合作 / 極端壓價 | | |
| 監管 / 社會 | 合規配合 / 打擦邊球 | | |

**李錄**:「對利益相關方嘅態度決定咗企業嘅長期生命力。短期壓榨能提升效率,但長期會損害生態。」

### 第四步:資本配置能力

呢個係巴菲特最看重嘅管理層能力 — **每賺一蚊,管理層能把佢變成幾多蚊?**

#### 4.1 資本配置決策記錄

搜公司過去 5 年嘅重大資本配置決策,逐筆評估:

**併購記錄**:

| 時間 | 收購標的 | 金額 | 戰略邏輯 | 事後回報 | 評分(1-5) |
|---|---|---|---|---|---|

**回購記錄**:

用 `~/.hermes/scripts/financial/financial_rigor.py verify-valuation` 校驗回購時和當前嘅 PE 等估值指標。

```bash
python3 ~/.hermes/scripts/financial/financial_rigor.py verify-valuation \
  --price {回購平均價} --eps {回購時EPS} --bvps {每股淨資產}
```

| 時間 | 回購金額 | 平均回購價 | 當時 PE | 事後回睇 | 評分(1-5) |
|---|---|---|---|---|---|

**分紅記錄**:

| 年份 | 分紅金額 | 分紅率 | 同期 FCF | 係咪可持續 |
|---|---|---|---|---|

**新業務投資**:

| 時間 | 投資領域 | 累計投入 | 當前狀態 | 回報評估 | 評分(1-5) |
|---|---|---|---|---|---|

#### 4.2 資本配置評分

| 維度 | 評分(1-5) | 說明 |
|---|---|---|
| 併購紀律 | | 是否在合理價格收購?收購後整合如何? |
| 回購時機 | | 是否在低估時回購、高估時停止? |
| 分紅合理性 | | 分紅率是否與 FCF 匹配? |
| 新業務投資 | | 成功率如何?止損紀律如何? |
| 現金管理 | | 現金儲備是否合理?是否囤積過多? |
| **綜合評分** | | |

**巴菲特標準**:理想嘅管理層喺有好機會時果斷投資,冇好機會時積極回購 / 分紅,永遠唔做高價併購。

#### 段永平嘅「買人」標準

> 回答以下三個問題:
> 1. **呢個人係咪正直?**(誠實、唔佔股東便宜)
> 2. **呢個人係咪有能力?**(戰略眼光 + 執行力 + 資本配置)
> 3. **你願唔願意將錢交俾呢個人管 10 年?**
>
> 三個都係「係」= ★★★★★ (5 分)
> 前兩個係「係」= ★★★★ (4 分)
> 只有第一個係「係」= ★★★ (3 分)
> 第一個唔係「係」= ★ (1 分,不投)

## 關鍵原則

- **誠信係一票否決項** — 能力不足可以學習,品格有問題無法修復
- **睇行為唔睇言辭** — 管理層講咩唔重要,做咗咩先重要
- **喺困難中睇真相** — 順風時邊個都係好 CEO,逆風時先見真功夫
- **資本配置係終極考試** — 賺錢容易,把賺到嘅錢配置好難
- **唔好愛上管理層** — 保持客觀,即使係你欣賞嘅人都可能犯大錯
