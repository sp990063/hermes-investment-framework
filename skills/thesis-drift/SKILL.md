# 投資論文漂移檢測:分清事實變化與措辭變化 (Hermes port)

對 $ARGUMENTS 進行投資論文漂移檢測。

> 「人最危險嘅錯誤係**混淆咗語言嘅變化同現實嘅變化**。」

---

## 設計理念

當你重讀自己嘅舊投資筆記,往往會發現:
- 用字變咗(從「明顯買入」變成「觀察」)
- 焦點移咗(從「護城河」變成「短期催化劑」)
- 但**你未必意識到**呢個係漂移

**漂移 3 類**:

| 漂移類型 | 危險度 | 例子 |
|---|---|---|
| **事實漂移**(基本面真變) | 低(應該) | 「收入增速從 30% 跌到 15%」 — 呢個真嘅要 review |
| **估值漂移**(市場 price 變) | 中 | 「股價跌 20% 但我嘅論文冇變」 — 可能係機會 |
| **措辭漂移**(你嘅心理變) | **高** | 「我 6 個月前話『護城河深』,而家話『等待催化劑』 — 思想已變,但無自覺」 |

**核心目標**:**第三種最危險,因為你唔自覺**。

## 執行流程

### 第一步:判斷操作模式

| 模式 | 觸發條件 | 操作 |

## 模式 A:指定報告對比

### A1:讀取並校驗兩份報告

```bash
read_file reports/{公司名}-thesis-20250101.md
read_file reports/{公司名}-thesis-20250701.md
```

驗證兩份報告都係對**同一間公司**(避免錯誤配對)。

### A2:證據歸一化

將兩份報告入面嘅**事實陳述**提取成結構化證據:

```
[證據 1] 2025Q1 收入 = HK$167B
[證據 2] 2025Q1 經營利潤率 = 28%
[證據 3] 2025Q1 PE = 18x
...
```

### A3:數值與估值校驗

用 `~/.hermes/scripts/financial/financial_rigor.py` 校驗:

```bash
# 如果兩個 snapshot 都聲稱「2025Q1 收入 = HK$167B」,驗證係咪一致
python3 ~/.hermes/scripts/financial/financial_rigor.py cross-validate \
  --field "2025Q1_revenue" \
  --values '{"old_thesis": 167000000000, "new_thesis": 167500000000}' \
  --unit HKD
```

### A4:逐維度判定漂移

| 維度 | 舊表述 | 新表述 | 漂移類型 | 顯著性 |
|---|---|---|---|---|
| 收入增長 | "30% YoY,強勁" | "20% YoY,穩健" | **事實+措辭** | 中 |
| 護城河 | "寬,5 類驗證" | "深,3 類驗證" | **事實**(可能競爭加劇) | 高 |
| 估值 | "折讓 18%" | "折讓 27%" | **估值** | 中 |
| 結論 | "明顯買入" | "觀察" | **措辭** | **高** |
| 持有期 | "5 年" | "3 年" | **措辭** | 中 |
| 加倉信號 | "PE < 15x" | "PE < 12x" | **措辭+估值** | 中 |

### A5:證據驅動規則

**漂移判斷必須由證據支持**,唔可以主觀:

| 漂移類型 | 證據要求 |
|---|---|
| 事實漂移 | 必須有對比嘅財務數據 |
| 估值漂移 | 必須有對比嘅股價 / 估值指標 |
| 措辭漂移 | 兩份文本嘅 quote 對比 |

### A6:輸出漂移報告

```markdown
## {公司名} 論文漂移檢測報告

**對比日期**: {舊} → {新}
**股價變化**: $480 → $510 (+6.3%)

### 漂移摘要

| 類型 | 數量 | 主要發現 |
|---|---|---|
| 事實漂移 | 2 | 收入增速下降 10pp;競爭加劇 |
| 估值漂移 | 1 | 折讓由 18% → 27% |
| 措辭漂移 | 3 | **重要**:結論由「買入」變「觀察」 |

### 詳細對比

[按維度展開]

### 解讀

- **事實部分**:基本面真嘅變差咗(收入 + 競爭),但唔係災難性
- **估值部分**:反而更便宜(折讓加大),可能係機會
- **措辭部分**:由「買入」變「觀察」 — **呢個係警示信號**,你嘅心理已經偏向 negative 但冇明確觸發紅線

### 建議

1. 重新檢視紅線清單 — 觸發咗邊啲?
2. 如果紅線未觸發,措辭漂移反映你嘅恐懼 — 問:呢個恐懼有事實支持嗎?
3. 如果事實漂移 + 估值漂移都支持減倉 → 果斷減倉
4. 如果事實漂移 + 估值漂移矛盾(基本面差但估值更便宜) → 重新做 `/investment-research` 深度
```

## 模式 B:自動快照對比

### B1:查找快照

```bash
ls reports/{公司名}-thesis-*.md
```

搵最新 2 份(默認)或最新 + 6 個月前 / 1 年前。

### B2:防止錯誤配對

| 風險 | 處理 |
|---|---|
| 公司名寫錯 | 校驗報告入面嘅 ticker / 業務描述 |
| 時間太接近(< 1 個月) | 提示漂移唔顯著,需更長時間 |
| 時間太遠(> 2 年) | 提示可能無可比性 |

### B3:執行模式 A

確認配對後,執行模式 A 嘅 A1-A6 步驟。

---

## 漂移嘅 3 大警示信號

> **如果出現以下任何一個,應該立即 review**

1. **結論由「買入」變「觀察 / 等待」** — 措辭已暗示退縮
2. **持有期由 5 年縮短到 1-2 年** — 你已經唔相信長期
3. **紅線數量增加** — 你喺度為「仲 hold 住」搵藉口

---

## 漂移嘅健康跡象

- 結論由「買入」保持「買入」,**即使期間股價跌 30%** — 論文健康
- 估值由「合理」變「明顯低估」 — 機會嚟咗
- 持有期由 5 年延長到 10 年 — 越嚟越有信心

## Token 控制

`/thesis-drift` 涉及讀取 + 對比兩份文件,token 消耗中等。建議:
- 對核心持倉**每季做一次**漂移檢測
- 對**情緒動搖時**(股價大跌 / 大升後)做一次
