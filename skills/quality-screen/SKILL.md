# 去劣篩選:7 條指標快速排除非一流公司 (Hermes port)

對 $ARGUMENTS 進行去劣篩選。**呢個係投資流程嘅最輕量 gatekeeper** — 用嚟快速排除明顯唔好嘅公司,先避免浪費 token 喺 investment-research / investment-team。

---

## 設計原則

- **快**(< 2 分鐘分析一家)
- **嚴**(7 條指標通過先算「一流」)
- **唔求完美**(呢個係初篩,深入分析留俾其他 skill)

> **重要**:Quality-screen 通過 = 值得用 `/investment-research` 或 `/investment-team` 深入研究。**唔等於值得買入。**

---

## 7 條去劣指標

| # | 指標 | 通過條件 | 失敗信號 |
|---|---|---|---|
| 1 | **ROIC > WACC** | ROIC / WACC > 1.5x | ROIC < WACC 反映資本配置差 |
| 2 | **FCF / Revenue > 5%** | 過去 3 年平均 | < 3% 反映盈利質量差 |
| 3 | **經營活動現金流 / 淨利潤 > 1** | 過去 3 年平均 | < 0.7 反映利潤靠應收 / 折舊 |
| 4 | **毛利率 > 30%**(個別行業豁免) | 過去 3 年平均 | < 20% 通常係差生意 |
| 5 | **資產負債率 < 60%**(金融業豁免) | 最近期 | > 80% 高槓桿風險 |
| 6 | **過去 5 年收入 ≥ 持平**(可豁免) | 收入 CAGR ≥ 0% | 持續萎縮通常無翻身 |
| 7 | **管理層誠信**(紅線一票否決) | 無重大負面事件 | 造假 / 欺詐 / 內幕交易 |

**7 條通過 = 入圍一流公司清單**(可進一步用 `/investment-team` 深度研究)
**6 條通過 = 觀察名單**(可能有特殊原因)
**≤ 5 條通過 = 淘汰**

---

## 3 條豁免規則

| 豁免 | 適用條件 | 處理 |
|---|---|---|
| **A:戰略投入期豁免** | 第 1 條 ROIC < WACC 但管理層有 track record 嘅戰略投入 | 第 1 條可豁免 1 期 |
| **B:主動低利潤率豁免** | 行業本身低毛利(如零售 / 物流)且公司市佔率上升 | 第 4 條可豁免 |
| **C:高週轉薄利模式豁免** | 高週轉率 + 高 ROIC 嘅模式(如 Costco / 沃爾瑪) | 第 4 + 6 條可豁免 |

## 執行流程

### 第一步:解析輸入,確定篩選範圍

**輸入格式**:
- 個股:`騰訊`、`PDD`、`茅台`
- 行業:`恒生指數成分股`、`標普 500`、`半導體`、`AI 算力`
- 主題:`AI 應用`、`核電`、`稀土`

**處理**:
1. 如果係個股 → 直接對該公司跑 7 條
2. 如果係行業 / 指數 / 主題 → 獲取成分股列表,然後對每間跑 7 條

### 第二步:並行數據收集

> **Hermes adaptation**:用 `delegate_task` 啟動 batch subagent 並行收集成分股嘅財務指標(A 股 / 港股 / 美股分開 batch)。

每個 subagent 對其 region 嘅每間公司提供:

```json
{
  "company": "...",
  "ticker": "...",
  "ROIC_5y_avg": 18.5,
  "WACC": 9.2,
  "FCF_revenue_3y_avg": 12.3,
  "CF_NI_3y_avg": 1.15,
  "gross_margin_3y_avg": 45.6,
  "debt_to_asset": 35.2,
  "revenue_5y_cagr": 8.5,
  "management_red_flags": []
}
```

### 第三步:逐條檢驗

對每家公司,按 7 條指標逐條檢驗。豁免規則需要**明確記錄理由**。

### 第四步:輸出結果

```markdown
## 去劣篩選結果 — {範圍}

### 通過嘅公司(N 家)
| 公司 | Ticker | ROIC/WACC | FCF/Rev | CF/NI | 毛利率 | 負債率 | 收入 5y CAGR | 結果 |
|---|---|---|---|---|---|---|---|---|
| 騰訊 | 0700.HK | 2.1x | 25% | 1.4 | 48% | 45% | +12% | ✅ 7/7 通過 |
| 茅台 | 600519 | 5.2x | 38% | 1.2 | 91% | 22% | +18% | ✅ 7/7 通過 |
| 美團 | 3690.HK | 0.9x | -3% | 0.5 | 28% | 60% | +35% | ⚠️ 5/7(戰略投入期豁免第 1 條)|

### 觀察名單(M 家)
- X: 6/7 通過,第 X 條因為 [理由] 未通過。持續追蹤。

### 淘汰名單
- Y: 4/7 通過,主要問題 [列原因]。
- Z: 3/7 通過,管理層有誠信問題(一票否決)。
```

## Token 控制

`quality-screen` 係**最輕量**嘅 skill。設計目的:
- 跑得快 → 唔好為咗 1 間公司燒 token
- 大量篩選 → 可以處理整個指數成分股(50-100 間)
- 用 `delegate_task` batch 拆 region 處理

**整個流程通常 5-10 分鐘,token 消耗中等**。如果用嚟做行業初步篩選,30-60 間公司亦可以喺合理時間內完成。
