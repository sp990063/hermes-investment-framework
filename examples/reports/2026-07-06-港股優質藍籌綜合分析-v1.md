#### §15 Intrinsic Value (DCF)

**方法**:Bank DCF = DDM (Dividend Discount Model)

| 參數 | Value |
|---|---|
| Current DPS | HK$0.36 |
| Dividend Growth Rate (5-yr avg) | ~3% |
| Required Return | 10% |
| **DDM Intrinsic** | HK$0.36 × (1+3%) / (10%-3%) = **HK$5.30** |

**BUT** — 銀行唔可以純用 DDM,因為佢需要保留資本。改用 **Residual Income Model**:

| 參數 | Value |
|---|---|
| Book Value Per Share | HK$6.43 / 0.59 = HK$10.90 |
| Sustainable ROE | 10% |
| Cost of Equity | 10% |
| Growth Rate | 3% |
| **Residual Income Intrinsic** | HK$10.90 + (10%-10%)×HK$10.90 / (10%-3%) = **HK$10.90** |

**綜合 DCF(50% DDM + 50% RIM)**:**HK$8.10**

#### §16 Margin of Safety

| Metric | Value |
|---|---|
| DCF Intrinsic | **HK$8.10** |
| Current Price | **HK$6.43** |
| **MoS** | **(8.10 - 6.43) / 8.10 = +20.6%** ⚠️ |

**Analyst Consensus Target**:HK$8.30(+29% upside)

**MoS 不算高(< 30%)但 analyst target 接近 DCF intrinsic**,Buffett 會喺呢個水位**慢慢建倉**。
