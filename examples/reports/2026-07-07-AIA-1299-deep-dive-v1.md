## §15 Intrinsic Value DCF(Embedded Value + VONB Approach)

> **核心 insight**:保險股 generic DCF 唔太適用,**需要 Embedded Value + VONB multi-period approach**。

### 15.1 Embedded Value(EV)Approach

EV 係保險股嘅 key valuation metric,代表 **現有保單 + 新業務未來 EV 折現**。

| Component | Value | Notes |
|---|---|---|
| **Adjusted Net Asset Value(ANAV)** | ~US$400 億 | 2025 |
| **Present Value of Future Profits(PVFP)** | ~US$397 億 | 2025 |
| **EV(2025 末)** | **~US$797 億** | 巳公佈 |
| **EVPS** | **~HK$60.0/股**(US$79.7B ÷ 10.353M shares × 7.78)| — |

### 15.2 VONB 增長 Projection(5 年)

假設 VONB 增長 **+12% CAGR**(略低於 2025 +15%,反映 maturation):

| Year | VONB(US$)| Cumulative |
|---|---|---|
| 2025A | 5.516B | Base |
| 2026E | 6.18B | +12% |
| 2027E | 6.92B | +12% |
| 2028E | 7.75B | +12% |
| 2029E | 8.68B | +12% |
| 2030E | 9.72B | +12% |

### 15.3 EV Projection(假設 VONB 以 8x P/E VONB multiple 創造 EV 增量)

| Year | EV(US$)| Notes |
|---|---|---|
| 2025A | 79.7B | — |
| 2026E | 84.7B | +5B VONB × 8 + ~0 |
| 2027E | 90.2B | +5.5B |
| 2028E | 96.4B | +6.2B |
| 2029E | 103.3B | +6.9B |
| 2030E | 110.9B | +7.6B |
| Terminal EV(NPV @ 6%)| 196B | 110.9B × 1.12 ÷ (0.10-0.12 等效)|

**2-Stage DCF**:
- PV of 5 年 EV 增量:(5 + 5.5 + 6.2 + 6.9 + 7.6) ÷ (1.08)^i × 折現係數
- + Terminal Value(假設 mature EV 增長 ~3% terminal,6% discount rate)

**Simplified**:**EVPS(2030E)~ HK$84** = 110.9B × 7.78 ÷ 10.353B
