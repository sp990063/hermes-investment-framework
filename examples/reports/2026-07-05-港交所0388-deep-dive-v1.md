## 15. ai-berkshire Framework v2.0 — Intrinsic Value (Owner Earnings DCF)

| Parameter | Value | Notes |

| **Current Owner Earnings TTM** | **~HKD 10B** | Net Income 12.5B × 80% retain |
| **Growth Rate (5年)** | **8%** | 中概股回流 + ADT 增長 |
| **Terminal Growth** | 3% | GDP-aligned |
| **Discount Rate** | **10%** | Buffett standard |
| **Terminal Exit Multiple** | 20x Owner Earnings | Monopoly premium |

### 15.2 DCF Calculation

```
DCF Value:
PV of 5-year Owner Earnings = 10B × (1.08 + 1.166 + 1.260 + 1.360 + 1.469) / (1.10)^0.5
                            ≈ 10B × 6.34 × 0.953
                            ≈ 60.4B

Terminal Value:
TV = (10B × 1.469 × 1.03) / (0.10 - 0.03) = 15.1B / 0.07 = 215.4B
PV of TV = 215.4B / (1.10)^5 = 215.4B / 1.611 = 133.7B

Total DCF = 60.4B + 133.7B = 194.1B HKD
Per share = 194.1B / 1,256M shares = HKD 154 / share
```

**Intrinsic Value Estimate: HKD 154 per share**
