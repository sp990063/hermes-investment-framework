### 15.2 DCF Calculation

```
DCF Value:
PV of 5-year Owner Earnings = 200B × (1.10 + 1.21 + 1.331 + 1.464 + 1.611) / (1.10)^0.5
                            ≈ 200B × 6.72 × 0.953
                            ≈ 1,280B

Terminal Value:
TV = (200B × 1.611 × 1.03) / (0.10 - 0.03) = 331.7B / 0.07 = 4,738B
PV of TV = 4,738B / (1.10)^5 = 4,738B / 1.611 = 2,941B

Total DCF = 1,280B + 2,941B = 4,221B RMB
Per share = 4,221B / 9,500M shares = RMB 444 / share
In HKD = 444 × 1.09 = **HK$484 per share**
```

**Intrinsic Value Estimate: HK$484 per share**
